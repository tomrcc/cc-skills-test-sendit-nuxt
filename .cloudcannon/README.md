# Sendit website

This is the Sendit marketing website: the home page, product pages, pricing, contact, the blog, and the navigation and footer shown on every page.

## Pages

Every page on the site, including the home page, is built from sections such as heroes, features, counters, testimonials, pricing tables and FAQs.

- **Edit a page:** open it from Pages. It opens in the Visual Editor, where you can click text and images on the page to change them.
- **Add, remove or reorder sections:** use the Page sections list in the sidebar.
- **Create a page:** click **+ Add** in Pages and choose Page. Give it a title; its address comes from the file name (a page saved as `services.md` is at `/services/`). To show it in the menu, add a link in Data → Navigation.
- **Delete a page:** delete its file from Pages, and remove any menu or footer links that point to it.

A new page previews on the home page until the site has been rebuilt with it.

## Blog

Blog posts, plus the Blog Index file that holds the blog's heading, intro text, posts per page, and the labels shown on every post.

- **Create a post:** click **+ Add** in Blog and choose Blog Post. Fill in the title, date, author, tags, and the thumbnail and featured images, then write the post.
- **Edit a post:** open it from Blog. It opens in the Visual Editor; the Content Editor is available for writing the post's text.
- **Tags:** pick tags from the list. Each tag has its own page listing its posts. Add new tags in Data → Tags.

A new post previews on the "Email delivery tips" post until the site has been rebuilt with it. If you delete or rename that post, new posts have no preview until they are built.

## Data

Settings shared across the whole site:

- **Navigation:** the logo, menu links and the button at the top of every page
- **Footer:** the logo, copyright text, social links and link columns at the bottom of every page
- **Site:** the site's name, address, default description and default social sharing images
- **Theme:** the site's colours
- **Tags:** the tags you can choose on blog posts

## Editing on the page

- **Menu and footer:** click their text and images on any page. The change is saved to Data → Navigation or Data → Footer and shows on every page.
- **Footer link columns:** edit a column's heading and links on the page; add, remove or reorder whole columns in Data → Footer.
- **"Written by:" and "Recent Blog" on a post:** these come from the Blog Index file, so changing them on one post changes them on every post.
- **Buttons and links:** click their text to change it. Change where they go in the sidebar.
- **Dates, switches and icons:** change these in the sidebar.
- **FAQ answers:** click a question to open its answer, then click the answer to edit it.

## Search and sharing

Every page and post has an SEO section for its search description, social sharing image, and whether search engines should list it. Anything left empty uses the defaults in Data → Site.
